# Memory Model

Tipos iniciais:

- `episode`: algo que aconteceu.
- `fact`: fato durável.
- `preference`: preferência do usuário ou organização.
- `procedure`: modo de fazer, regra ou workflow.
- `relation`: relação lógica/temporal entre memórias.

Campos essenciais:

- tenant_id, user_id, agent_id, project_id, session_id
- type, content, summary
- source_event_ids
- confidence, importance
- valid_from, valid_until
- status, scope, version
- safety_labels
